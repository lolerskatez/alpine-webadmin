QUICK START (3 STEPS)
================================================================================

Step 1: Build on development machine
  cd alpine-webadmin
  chmod +x setup.sh
  ./setup.sh build

Step 2: Transfer binaries to testbench
  scp bin/webadmin bin/roothelper root@testbench:/tmp/

Step 3: Deploy on testbench
  cd alpine-webadmin
  sudo ./setup.sh deploy

Result: Services running on http://localhost:8080

USAGE
================================================================================

./setup.sh [command]

Commands:
  build       Build binaries only (requires Go 1.22+)
  deploy      Deploy pre-built binaries (requires root)
  all         Build and deploy in one step (requires root for deploy)
  help        Show help message

Examples:

  # Build on development machine
  ./setup.sh build

  # Deploy to testbench
  sudo ./setup.sh deploy

  # Build and deploy in one step
  sudo ./setup.sh all

================================================================================
WHAT GETS INSTALLED
================================================================================

Binaries:
  /usr/sbin/webadmin      — HTTP/WebSocket server
  /usr/sbin/roothelper    — Privileged IPC daemon

Configuration:
  /etc/webadmin/config.json    — Main configuration
  /etc/webadmin/passwd         — Password hash

Directories:
  /run/webadmin/          — Runtime socket and PID files
  /var/log/webadmin/      — Log files

Services:
  /etc/init.d/webadmin    — OpenRC init script
  /etc/init.d/roothelper  — OpenRC init script

User:
  webadmin                — System user (unprivileged)

================================================================================
TROUBLESHOOTING
================================================================================

Build fails?
  - Check Go version: go version
  - Check internet: ping 8.8.8.8
  - Check disk space: df -h /

Deployment fails?
  - Check root access: id
  - Check binaries: ls -l bin/webadmin bin/roothelper
  - Check permissions: ls -ld /usr/sbin

Services won't start?
  - Check logs: tail -50 /var/log/webadmin/*.log
  - Check port: netstat -tlnp | grep 8080
  - Check socket: ls -l /run/webadmin/ipc.sock

See SETUP_GUIDE.md for detailed troubleshooting.
